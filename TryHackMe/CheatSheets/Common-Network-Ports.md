# Common Network Ports

| Port  | Protocol | Service |
| ----- | -------- | ------- |
| 20/21 | TCP      | FTP     |
| 22    | TCP      | SSH     |
| 23    | TCP      | Telnet  |
| 25    | TCP      | SMTP    |
| 53    | TCP/UDP  | DNS     |
| 80    | TCP      | HTTP    |
| 110   | TCP      | POP3    |
| 143   | TCP      | IMAP    |
| 443   | TCP      | HTTPS   |
| 445   | TCP      | SMB     |
| 3389  | TCP      | RDP     |

## Notes

### SSH (22)

Used for secure remote access to systems.

### HTTP (80)

Used for unencrypted web traffic.

### HTTPS (443)

Used for encrypted web traffic using TLS/SSL.

### DNS (53)

Used to translate domain names into IP addresses.

### RDP (3389)

Used for remote access to Windows systems.
