# TryHackMe - Cyber Security 101

## Overview

Cyber Security 101 is a beginner-friendly learning path on TryHackMe designed to build a strong foundation in cyber security. The path introduces learners to both offensive and defensive security concepts while gradually developing practical skills through hands-on labs and guided exercises.

The learning path covers networking, operating systems, cryptography, web security, system exploitation, security monitoring, digital forensics, security tools, and cyber security career fundamentals. It is designed for complete beginners who want to start a journey toward careers in Penetration Testing, SOC Analysis, Incident Response, Digital Forensics, or other cyber security roles.

---

## Learning Objectives

By completing this path, learners will be able to:

* Understand the fundamentals of cyber security.
* Learn the basics of offensive and defensive security.
* Work with Linux and Windows operating systems.
* Understand Active Directory fundamentals.
* Use command-line interfaces in Windows and Linux.
* Learn networking concepts, protocols, and traffic analysis.
* Understand cryptography and password security.
* Perform basic exploitation activities.
* Understand web application security fundamentals.
* Use common offensive security tools.
* Learn SOC operations and defensive security practices.
* Understand security monitoring technologies.
* Explore cyber security career paths and industry fundamentals.
* Gain awareness of modern OWASP Top 10 risks.

## Key Takeaways

* Cyber security consists of both offensive and defensive disciplines.
* Strong networking knowledge is essential for all cyber security roles.
* Linux and Windows skills form the foundation of technical security work.
* Security professionals rely heavily on command-line tools.
* Understanding logs and network traffic is critical for investigations.
* Security tools are effective only when supported by strong foundational knowledge.
* Continuous learning is required because threats and technologies constantly evolve.
