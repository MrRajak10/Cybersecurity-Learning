# Search Skills | TryHackMe

## Overview

**Search Skills** is a foundational TryHackMe room that teaches one of the most valuable skills in cybersecurity: finding accurate information efficiently.

Cybersecurity professionals constantly research vulnerabilities, commands, tools, attack techniques, documentation, threat intelligence, and security news. Knowing **where** to search and **how** to evaluate search results is just as important as understanding the technical concepts themselves.

This room focuses on developing effective research habits instead of memorizing information.

---

## Search Engine Operators

Search operators help narrow results and make searches more precise.

Examples include:

* Exact phrase searches
* Searching within a specific website
* Excluding unwanted keywords
* Searching for specific file types

These operators reduce unnecessary results and make research much faster.

---

## Specialized Search Engines

Instead of searching the entire web, specialized search engines focus on specific types of information.

Examples include:

* Internet-connected devices
* Hosts and certificates
* Malware analysis
* Public data breaches

These tools are commonly used during both offensive and defensive security work.

---

## Vulnerability Research

The room introduced important vulnerability resources.

### CVE

A standardized identifier for publicly known vulnerabilities.

### National Vulnerability Database (NVD)

Provides detailed technical information about vulnerabilities.

### Exploit Database

Contains publicly available exploits for many vulnerabilities.

### GitHub

Often contains proof-of-concept exploits, research projects, tools, and security scripts.

---

## Technical Documentation

Official documentation should always be the first reference when learning a command or technology.

Examples include:

* Linux manual pages
* Microsoft documentation
* Official product documentation

Learning to read documentation is an essential cybersecurity skill.

---

## Social Media in Cybersecurity

Social media can provide valuable information for:

* Threat intelligence
* Security news
* OSINT
* Company research
* Employee profiling during authorized security assessments

The room also highlights the importance of understanding the security risks of oversharing personal information online.

# Beginner Practice Activities

To reinforce the concepts learned in this room, try the following exercises:

### Practice 1

Search for a Linux command using:

* Official documentation
* Community blog
* AI assistant

Compare the explanations and identify the differences.

---

### Practice 2

Practice using search operators to:

* Search an exact phrase.
* Search within a specific website.
* Search for PDF files.
* Exclude unwanted keywords.

---

### Practice 3

Choose a public CVE and research:

* What the vulnerability affects.
* Its severity.
* Available mitigations.
* Whether a public exploit exists.

---

### Practice 4

Look up a common file hash or URL using VirusTotal and explore the information available.

---

### Practice 5

Read the official documentation for a Linux command and compare it with an online tutorial.
