# TryHackMe — Windows Fundamentals

## Overview

This repository contains my learning notes and experience from the **Windows Fundamentals** room on TryHackMe. The purpose of this repository is to document the concepts I learned while exploring the Windows operating system from a cybersecurity perspective. Instead of focusing on simply completing the room, this repository focuses on understanding how Windows works, why its components are important, and how this knowledge helps in real-world cybersecurity.

This room helped me become familiar with the Windows desktop environment, important system components, user management, file systems, permissions, system utilities, and basic administrative tools that every cybersecurity beginner should know before moving to more advanced topics.

---

# Learning Objectives

After completing this room, I was able to:

* Understand the basic structure of the Windows operating system.
* Navigate the Windows desktop and graphical user interface (GUI).
* Explore the Start Menu, Taskbar, Notification Area, and Settings.
* Understand different Windows file systems.
* Learn the purpose of important Windows folders.
* Explore Windows environment variables.
* Understand user accounts, groups, and permissions.
* Learn the basics of User Account Control (UAC).
* Use Windows administrative tools.
* Understand the purpose of Task Manager.
* Build a stronger foundation for future Windows security topics.

# Topics Covered

## Windows Graphical User Interface (GUI)

The room introduced the Windows graphical user interface and explained how users interact with the operating system through icons, windows, menus, buttons, and graphical elements instead of typing commands.

Topics included:

* Desktop
* Icons
* Start Menu
* Taskbar
* Notification Area
* Search
* Settings
* Lock Screen
* Personalization

---

## Windows Start Menu

The Start Menu acts as the central location for accessing applications, settings, user options, and power controls.

Important areas include:

* Recently installed applications
* Frequently used applications
* User account
* Power options
* Search functionality

---

## Taskbar

The Taskbar allows quick access to applications and running programs.

It also provides access to:

* Running applications
* Search
* Notification Area
* Clock
* Network status
* Volume controls
* Calendar

---

## Notification Area

The Notification Area provides quick access to important system information such as:

* Network connectivity
* Sound settings
* Battery status
* Date and time
* Background notifications

---

## Windows File Systems

The room introduced different Windows file systems and explained their purpose.

Examples include:

* FAT16
* FAT32
* NTFS

I learned that modern Windows systems primarily use **NTFS** because it supports permissions, security features, reliability, and large file sizes.

---

## Important Windows Folders

Several important Windows directories were introduced during the room.

Examples include:

* Windows Folder
* System32
* Users
* Program Files
* Temporary folders

I learned that these folders contain critical operating system files and should not be modified without understanding their purpose.

---

## Environment Variables

Environment Variables store useful information that Windows and applications use while running.

Examples include:

* System paths
* Temporary directories
* User profile locations

Understanding environment variables is useful for troubleshooting, scripting, and system administration.

---

## User Accounts

The room explained how Windows manages users.

Topics included:

* Administrator accounts
* Standard users
* User profiles
* Local users
* User management

Understanding user accounts is essential because permissions determine what actions users are allowed to perform.

---

## Local Users and Groups

Windows allows administrators to manage:

* Users
* Groups
* Permissions
* Membership

Different groups provide different privilege levels inside the operating system.

---

## User Account Control (UAC)

User Account Control (UAC) helps protect Windows by asking for permission before allowing actions that require administrative privileges.

I learned that UAC helps reduce accidental or unauthorized system changes.

---

## Windows Permissions

The room introduced basic Windows permissions.

Examples include:

* Read
* Write
* Execute
* Modify
* Full Control

These permissions determine what users can do with files and folders.

---

## Task Manager

Task Manager is one of the most useful Windows administrative tools.

It allows users to monitor:

* Running processes
* Performance
* Services
* Startup applications
* Resource usage

Learning Task Manager is important because it is commonly used during troubleshooting and incident investigations.

# Beginner Practice

After completing this room, practice the following activities:

1. Explore every option available in the Windows Settings application.
2. Open Task Manager and observe running processes.
3. Navigate through the Windows, Users, and System32 folders.
4. View your environment variables.
5. Explore Local Users and Groups (if available on your Windows edition).
6. Check file and folder permissions.
7. Compare NTFS with FAT32 by researching their differences.
8. Practice using the Windows Search feature to locate administrative tools.
