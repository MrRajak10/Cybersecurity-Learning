# Commands Learned

| Command  | Purpose                                                        |
| -------- | -------------------------------------------------------------- |
| `echo`   | Display text in the terminal                                   |
| `whoami` | Show the current logged-in user                                |
| `ls`     | List files and directories                                     |
| `cd`     | Change directory                                               |
| `pwd`    | Display the current working directory                          |
| `cat`    | Display file contents                                          |
| `find`   | Search for files                                               |
| `grep`   | Search inside files                                            |
| `>`      | Redirect output (overwrite)                                    |
| `>>`     | Append output to a file                                        |
| `&`      | Run a command in the background                                |
| `&&`     | Execute the next command only if the previous command succeeds |

# Challenges Faced

As a beginner, the terminal initially felt unfamiliar because there is no graphical interface to guide navigation. Remembering command names and understanding directory movement required practice. Differentiating between similar shell operators, especially `>` and `>>`, also required careful attention.

With repeated use, these commands gradually became easier to remember and understand.
