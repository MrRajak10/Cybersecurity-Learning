# Windows Fundamentals 3

> A beginner-friendly learning repository for the **Windows Fundamentals 3** room on TryHackMe. This repository focuses on understanding Windows security features, why they exist, and how they help protect systems. The goal is learning, not simply completing the room.

---

# Room Overview

Windows Fundamentals 3 introduces the security features built into Microsoft Windows. While the previous Windows Fundamentals rooms focused on navigating and understanding the operating system, this room shifts attention toward the defensive technologies that help secure Windows devices against modern threats.

Throughout the room, learners explore Microsoft's built-in security tools, understand their purpose, and see how they work together to protect a computer from malware, ransomware, unauthorized access, and other security risks.

---

# Learning Objectives

After completing this room, you should be able to:

* Understand the importance of Windows Update.
* Explain why security patches are critical.
* Navigate Windows Security.
* Identify the purpose of Microsoft Defender.
* Understand Real-time Protection.
* Explain how Windows Defender Firewall protects a system.
* Differentiate between Domain, Private, and Public network profiles.
* Understand Microsoft Defender SmartScreen.
* Explain Device Security and Memory Integrity.
* Understand the purpose of TPM (Trusted Platform Module).
* Explain how BitLocker protects sensitive data.
* Understand the purpose of Volume Shadow Copy Service (VSS).
* Recognize how multiple Windows security features work together to create layered security.

# Key Concepts Learned

This room demonstrates that Windows includes multiple built-in defensive technologies rather than relying on a single security feature. Each component protects a different part of the operating system, creating a layered defense strategy.

Some features focus on preventing attacks before they occur, while others help detect malicious activity or recover data after an incident. Understanding when each feature is used is an important step toward learning Windows security.

# Beginner Takeaways

* Keep Windows updated.
* Do not disable built-in security features without understanding the consequences.
* Leave default security settings enabled unless you have a valid reason to change them.
* Understand the purpose of each security feature before attempting to configure it.
* Security is strongest when multiple protections work together.
