# TryHackMe — Windows Fundamentals 2

## Overview

**Windows Fundamentals 2** builds upon the concepts introduced in Windows Fundamentals 1 and focuses on the core Windows administration tools that every beginner in cybersecurity should understand. Instead of concentrating on exploitation, this room introduces the tools that Windows administrators, SOC analysts, incident responders, and penetration testers regularly use to investigate, troubleshoot, and manage Windows systems.

Throughout this room, I explored several built-in Windows utilities, learned their purpose, understood when they are used, and practiced navigating different system management interfaces. The room emphasizes understanding Windows rather than memorizing commands, making it an excellent foundation for anyone starting a cybersecurity journey.

---

# Learning Objectives

After completing this room, I was able to understand:

* The purpose of System Configuration (MSConfig).

* Advanced System Settings and performance options.

# Topics Covered

## System Configuration (MSConfig)

I learned how the **System Configuration** utility helps troubleshoot Windows startup issues and manage the Windows boot process.

The room introduced the five main tabs available inside MSConfig:

* General
* Boot
* Services
* Startup
* Tools

I learned how Windows can boot in different modes and how administrators can control which services load during startup.

---

## Boot Configuration

This section introduced different Windows boot options.

Some important concepts included:

* Normal Boot
* Diagnostic Startup
* Selective Startup
* Safe Boot
* No GUI Boot

I learned that Safe Mode starts Windows with only the minimum drivers and services required, making it useful for troubleshooting system problems.

---

## Windows Services

I explored how Windows runs many background services that support the operating system and installed applications.

During this section I learned how to:

* View running services
* View stopped services
* Identify service manufacturers
* Understand service status

Understanding services is important because malware often installs or modifies Windows services to maintain persistence.

---

## Startup Applications

I learned how Windows manages startup applications and why unnecessary startup programs can affect boot performance.

Instead of using MSConfig, modern Windows versions recommend managing startup applications through **Task Manager**.

---

## Windows Administrative Tools

The Tools tab inside MSConfig provides shortcuts to many built-in Windows administration utilities.

Examples include:

* Event Viewer
* Computer Management
* Task Manager
* About Windows
* UAC Settings
* System Information

I also learned that almost every Windows administrative tool can be launched using its executable or command.

---

## Advanced System Settings

This section introduced advanced Windows configuration options.

Important topics included:

* Performance settings
* Virtual Memory
* Page File
* Startup and Recovery
* Memory Dump configuration

One important concept I learned is that Windows uses the Page File as virtual memory whenever physical RAM becomes insufficient.

---

## User Account Control (UAC)

I learned how User Account Control protects Windows by asking for confirmation before important system changes are made.

The room explained the different notification levels available in UAC and why disabling UAC is generally not recommended.

---

## Computer Management

Computer Management combines multiple Windows administration tools into a single interface.

Major sections explored included:

* System Tools
* Storage
* Services and Applications

This utility acts as a central management console for Windows administration.

---

## Task Scheduler

I learned how Windows can automatically execute tasks based on predefined triggers.

Examples include:

* System startup
* User logon
* Daily schedules
* Weekly schedules
* Custom triggers

Understanding Task Scheduler is valuable because legitimate software and attackers both use scheduled tasks for automation.

---

## Event Viewer

This was one of the most important topics in the room.

I learned that Event Viewer stores logs generated by Windows and installed applications.

Important event types include:

* Error
* Warning
* Information
* Success Audit
* Failure Audit

I also explored common Windows log categories such as:

* Application Logs
* Security Logs
* System Logs
* Custom Logs

These logs are extremely valuable during troubleshooting, digital forensics, and security investigations.

---

## Shared Folders

I learned how Windows manages shared resources across the network.

This section introduced:

* Shared folders
* Open files
* Active sessions

These features help administrators monitor file sharing activity.

---

## Local Users and Groups

I explored how Windows manages local user accounts and security groups.

Important concepts included:

* User accounts
* Security groups
* Administrative privileges
* Group membership

Understanding permissions is an important part of Windows security.

---

## Performance Monitoring

The room introduced Windows Performance Monitor and explained how administrators can observe system activity in real time.

Performance data helps identify:

* CPU utilization
* Memory usage
* Disk activity
* System bottlenecks

---

## Device Manager

I learned that Device Manager is responsible for managing Windows hardware devices.

Examples include:

* Keyboard
* Mouse
* Display
* Storage devices
* Network adapters

It also helps troubleshoot hardware driver problems.

---

## Disk Management

Disk Management allows administrators to manage storage devices.

Common operations include:

* Creating partitions
* Extending partitions
* Shrinking partitions
* Assigning drive letters
* Managing disk volumes

---

## System Information

The System Information utility provides detailed information about the computer.

This includes:

* Hardware Resources
* Components
* Software Environment
* Network Information
* Environment Variables

It is useful when gathering system information during troubleshooting or incident investigations.

---

## Resource Monitor

I learned how Resource Monitor displays real-time resource usage.

Major monitoring categories include:

* CPU
* Memory
* Disk
* Network

This tool helps identify which processes consume system resources.

---

## Useful Windows Commands

The room introduced several useful Command Prompt commands.

Some examples include:

* hostname
* whoami
* ipconfig
* ipconfig /all
* netstat
* net help

These commands provide valuable information about the system, current user, network configuration, and active network connections.

---

## Windows Registry

Finally, I explored the Windows Registry.

The Registry acts as the central configuration database for Windows.

It stores configuration information related to:

* Windows settings
* Installed software
* User profiles
* Hardware configuration
* System configuration

I also learned how to open and navigate Registry Editor safely.

---

# Key Takeaways

* Windows includes many powerful built-in administration tools.
* Understanding these tools is essential before learning advanced cybersecurity topics.
* Event Viewer is one of the most valuable resources for security investigations.
* Resource Monitor and Performance Monitor help troubleshoot system performance.
* Computer Management centralizes several administrative tools.
* The Windows Registry stores critical operating system configuration.
* Command Prompt remains an important interface for Windows administration.
* Learning how Windows normally works makes detecting abnormal behavior much easier.
