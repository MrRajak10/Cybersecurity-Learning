# Key Concepts Learned

## Defensive Security

Defensive Security focuses on protecting systems, networks, and data from cyber attacks.

Its primary goals are:

* Prevent attacks before they happen.
* Detect attacks quickly.
* Respond to incidents to reduce damage.

---

## Blue Team

The Blue Team is responsible for defending an organization's infrastructure.

Typical responsibilities include:

* Monitoring systems
* Detecting suspicious activity
* Responding to incidents
* Improving security controls
* Reducing organizational risk

---

## Common Defensive Security Tasks

* Security awareness training
* Asset management
* Vulnerability patching
* Firewall configuration
* Intrusion Prevention Systems (IPS)
* Logging and monitoring
* Security policy enforcement

---

## Security Operations Center (SOC)

A Security Operations Center is a team that continuously monitors an organization's infrastructure for security threats.

SOC analysts investigate:

* Vulnerabilities
* Policy violations
* Unauthorized access
* Network intrusions
* Suspicious user activity

---

## Threat Intelligence

Threat Intelligence is the process of collecting, analyzing, and using information about cyber threats.

The objective is to understand attackers before they successfully compromise an organization.

Typical sources include:

* Network logs
* Public threat feeds
* Security forums
* Open-source intelligence (OSINT)

---

## Digital Forensics

Digital Forensics involves collecting and analyzing digital evidence after a security incident.

Evidence may include:

* File systems
* Memory dumps
* System logs
* Network traffic
* Deleted files
* Disk images

---

## Incident Response

Incident Response is the structured process used to handle security incidents.

The four major phases are:

1. Preparation
2. Detection and Analysis
3. Containment, Eradication, and Recovery
4. Post-Incident Activity

The objective is to minimize damage while restoring systems safely.

---

## Malware Analysis

The room introduced several common malware types.

### Virus

Malicious code that attaches itself to other programs and spreads between systems.

### Trojan

Software that appears legitimate but secretly performs malicious actions.

### Ransomware

Malware that encrypts files and demands payment for recovery.

---

## Malware Analysis Techniques

### Static Analysis

Study malware without executing it.

### Dynamic Analysis

Run malware inside an isolated environment and observe its behavior.

# Key Takeaways

* Defensive Security focuses on protecting systems rather than attacking them.
* Continuous monitoring is essential for detecting threats early.
* SIEM platforms help analysts identify suspicious activity from multiple log sources.
* Threat Intelligence improves an organization's ability to prepare for future attacks.
* Digital Forensics helps investigators understand how an incident occurred.
* Incident Response follows a structured process to reduce business impact.
* Malware analysis helps security professionals understand attacker behavior.
* Effective security depends on prevention, detection, investigation, and response working together.
