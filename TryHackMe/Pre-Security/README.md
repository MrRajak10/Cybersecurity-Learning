# Pre Security

This folder contains my notes, exercises, and key takeaways from the TryHackMe Pre Security learning path.

## Path Overview

The Pre Security path provides foundational knowledge required to understand cybersecurity concepts and technologies.

### Topics Covered

* Introduction to Cyber Security
* Network Fundamentals
* How The Web Works
* Computer Fundamentals
* Operating Systems Basics
* Software Basics
* Attacks and Defenses

## Goal

Build a strong understanding of how computers, networks, operating systems, web technologies, and security concepts work before moving into advanced cybersecurity topics.
