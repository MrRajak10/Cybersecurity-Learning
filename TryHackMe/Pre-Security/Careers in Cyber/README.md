# Careers in Cyber

## Room Overview

This repository contains my learning notes and experience from the **Careers in Cyber** room on TryHackMe.

Unlike technical rooms that focus on hands-on hacking or defensive investigations, this room introduces the different career opportunities available in the cybersecurity industry. It helps beginners understand that cybersecurity is much broader than just ethical hacking or SOC analysis.

The room provides an overview of several job roles, their responsibilities, required skills, and suggested learning paths for individuals interested in entering the cybersecurity field.

---

## Learning Objectives

By completing this room, I learned:

* Why cybersecurity is a growing industry
* Different career paths available in cybersecurity
* The responsibilities of various security professionals
* The difference between offensive and defensive security roles
* Which TryHackMe learning paths align with specific career goals
* How different security teams work together to protect organizations

## Cybersecurity Career Roles Covered

### Security Analyst

A Security Analyst helps protect an organization's systems and data by monitoring security events, identifying risks, and supporting security improvements.

#### Key Responsibilities

* Monitor organizational security
* Analyze threats and vulnerabilities
* Create security reports
* Develop security improvement plans
* Research emerging attack techniques

#### Suggested Learning Paths

* Pre Security
* Cyber Security 101
* SOC Level 1

---

### Security Engineer

Security Engineers design, implement, and maintain security controls that protect systems and networks.

#### Key Responsibilities

* Implement security solutions
* Monitor infrastructure security
* Mitigate vulnerabilities
* Improve security architecture
* Strengthen organizational defenses

#### Suggested Learning Paths

* SOC Level 1
* JR Penetration Tester
* Offensive Pentesting

---

### Incident Responder

Incident Responders handle security incidents while attacks are actively occurring.

#### Key Responsibilities

* Create incident response plans
* Investigate security incidents
* Coordinate response activities
* Reduce incident impact
* Improve future response procedures

#### Important Metrics

* MTTD – Mean Time To Detect
* MTTA – Mean Time To Acknowledge
* MTTR – Mean Time To Recover

#### Suggested Learning Path

* SOC Level 1

---

### Digital Forensics Examiner

Digital Forensics Examiners investigate cyber incidents and collect digital evidence.

#### Key Responsibilities

* Collect digital evidence
* Preserve evidence integrity
* Analyze systems and artifacts
* Document findings
* Produce investigation reports

---

### Malware Analyst

Malware Analysts study malicious software to understand its behavior and develop detection methods.

#### Key Responsibilities

* Perform static analysis
* Conduct dynamic analysis
* Reverse engineer malware
* Analyze malware behavior
* Document findings

#### Important Skills

* Assembly Language
* C Programming
* Reverse Engineering
* Operating System Internals

---

### Penetration Tester

Penetration Testers ethically hack systems to identify vulnerabilities before attackers do.

#### Key Responsibilities

* Test applications and networks
* Identify vulnerabilities
* Assess security risks
* Produce security reports
* Recommend remediation actions

#### Suggested Learning Paths

* JR Penetration Tester
* Offensive Pentesting

---

### Red Teamer

Red Teamers simulate real-world attackers to test an organization's detection and response capabilities.

#### Key Responsibilities

* Emulate threat actors
* Maintain persistence
* Evade detection
* Test security controls
* Assess incident response effectiveness

#### Suggested Learning Paths

* JR Penetration Tester
* Offensive Pentesting
* Red Teamer

## My Learning Experience

This room was straightforward and beginner-friendly.

I did not face major technical difficulties because the room focuses on career awareness rather than hands-on challenges. However, it helped me understand an important lesson: cybersecurity is much larger than just Red Teaming and Blue Teaming.

Before completing this room, I mainly knew about penetration testing and SOC roles. After finishing it, I learned about several specialized careers such as:

* Incident Response
* Digital Forensics
* Malware Analysis
* Security Engineering
* Security Analysis
* Red Team Operations

This broadened my understanding of the cybersecurity industry and helped me see the different directions I can pursue in the future.
