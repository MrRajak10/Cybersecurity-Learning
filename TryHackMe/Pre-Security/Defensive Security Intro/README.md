# Defensive Security Intro

## Overview
This repository contains my learning notes and takeaways from the **Defensive Security Intro** room on TryHackMe.
The room serves as an introduction to the defensive side of cybersecurity and explains how security teams work to prevent, detect, investigate, and respond to cyber threats. It introduces core blue-team concepts such as Security Operations Centers (SOC), Threat Intelligence, Digital Forensics, Incident Response, Malware Analysis, and SIEM-based alert monitoring.

## Room Topics
### Defensive Security
Defensive Security focuses on:
  * Preventing cyber attacks
  * Detecting malicious activities
  * Responding to security incidents
  * Protecting organizational assets
Common defensive activities include:
  * Security awareness training
  * Asset management
  * Patch management
  * Firewall deployment
  * Intrusion Prevention Systems (IPS)
  * Logging and monitoring

---

### Security Operations Center (SOC)
A SOC is responsible for monitoring and protecting an organization's infrastructure.
Key responsibilities include:
  * Monitoring security alerts
  * Detecting intrusions
  * Investigating suspicious activity
  * Responding to incidents
  * Supporting vulnerability management

---

### Threat Intelligence
Threat Intelligence helps organizations understand:
  * Potential attackers
  * Their motivations
  * Their tactics, techniques, and procedures (TTPs)
The process generally involves:
  1. Data Collection
  2. Data Processing
  3. Analysis
  4. Actionable Recommendations

---

### Digital Forensics
Digital Forensics focuses on investigating cyber incidents using digital evidence.
Important evidence sources include:
  * File systems
  * Memory dumps
  * System logs
  * Network logs

---

### Incident Response
The four major phases of Incident Response are:
  1. Preparation
  2. Detection and Analysis
  3. Containment, Eradication, and Recovery
  4. Post-Incident Activity
The goal is to minimize damage and restore normal operations as quickly as possible.

---

### Malware Analysis
Common malware categories include:
  * Virus
  * Trojan Horse
  * Ransomware
Two primary analysis methods:
  * Static Analysis
  * Dynamic Analysis

---

### SIEM Investigation Simulation
The practical section introduced a simplified SIEM environment.
Key lessons learned:
  * Not every alert indicates an attack.
  * Analysts must investigate before escalating.
  * IP reputation checks can help identify malicious activity.
  * Escalation procedures are important when suspicious activity is confirmed.
  * Blocking malicious IPs is a common defensive action.
