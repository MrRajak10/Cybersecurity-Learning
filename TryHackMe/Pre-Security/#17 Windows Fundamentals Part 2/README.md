# Windows Fundamentals Part 2

## Room Overview

This room continues the Windows Fundamentals learning path and focuses on several important Windows administration and monitoring tools. The room introduces System Configuration (MSConfig), Advanced System Settings, User Account Control (UAC), Computer Management, System Information, Resource Monitor, Command Prompt utilities, and the Windows Registry.

The objective of this room is not only to learn where these tools are located but also to understand how Windows administrators and security professionals use them to manage, troubleshoot, monitor, and investigate Windows systems.

---

## Learning Objectives

By completing this room, I learned how to:

* Navigate and use System Configuration (MSConfig)
* Understand Windows boot options and startup settings
* Explore Advanced System Settings
* Understand User Account Control (UAC)
* Use Computer Management and its various components
* Analyze logs using Event Viewer
* Review system information using System Information
* Monitor system resources using Resource Monitor
* Use important Command Prompt commands
* Understand the purpose of the Windows Registry

## Topics Covered

### System Configuration (MSConfig)

MSConfig is a Windows troubleshooting utility that helps administrators manage startup behavior and diagnose boot-related issues.

The main tabs explored in this section were:

* General
* Boot
* Services
* Startup
* Tools

Important concepts learned:

* Normal Startup loads all services and drivers.
* Diagnostic Startup loads only essential services.
* Selective Startup allows manual control over what loads during startup.
* Safe Boot starts Windows with minimal drivers and services.
* Startup applications can be managed through Task Manager.
* The Tools tab provides shortcuts to many useful Windows administrative utilities.

---

### Advanced System Settings

This section focused on two important areas:

#### Performance Settings

Performance settings control:

* Virtual memory
* Paging files
* Visual effects
* System performance optimization

I learned that when physical RAM becomes full, Windows can use virtual memory stored on disk to continue operating.

#### Startup and Recovery

Startup and Recovery settings allow administrators to:

* Configure system crash behavior
* Select memory dump types
* Troubleshoot system failures

Common memory dump options include:

* Small Memory Dump
* Kernel Memory Dump
* Complete Memory Dump
* Automatic Memory Dump

---

### User Account Control (UAC)

User Account Control helps prevent unauthorized changes to the operating system.

The room demonstrated the four UAC notification levels:

1. Always Notify
2. Notify Me Only When Apps Try To Make Changes (Default)
3. Notify Without Dimming Desktop
4. Never Notify

Key takeaway:

UAC acts as an additional security layer by requesting permission before sensitive system changes are made.

### Computer Management

Computer Management combines multiple administrative tools into a single console.

Main sections explored:

#### System Tools

* Task Scheduler
* Event Viewer

* Performance Monitor
* Device Manager

#### Storage

* Disk Management

#### Services and Applications

* Windows Services

### Task Scheduler

Task Scheduler allows Windows to automatically execute tasks based on triggers.

Examples:

* Run at system startup
* Run daily
* Run weekly
* Run at user logon

I found it interesting to see how many background tasks Windows schedules automatically without user interaction.

---

### Event Viewer

Event Viewer stores logs generated by Windows and applications.

Important event types:

* Error
* Warning
* Information
* Success Audit
* Failure Audit

Important log categories:

* Application Logs
* Security Logs
* System Logs
* Custom Logs

From a cybersecurity perspective, Security Logs were particularly interesting because they record authentication and security-related events.

---

### Shared Folders

The Shared Folders section displays:

* Shared resources
* Active sessions
* Open files

This helps administrators monitor resources that are accessible across a network.

---

### Local Users and Groups

This area allows administrators to:

* Manage local user accounts
* Create groups
* Assign permissions
* Control access rights

Understanding groups helped me realize how Windows simplifies permission management for multiple users.

---

### Performance Monitor

Performance Monitor provides real-time performance data.

It can be used to monitor:

* CPU usage
* Memory usage
* Disk activity
* Network activity

This tool is useful when investigating performance issues or resource bottlenecks.

---

### Device Manager

Device Manager is used to manage hardware devices installed on the system.

Examples include:

* Keyboards
* Mice
* Monitors
* Network Adapters
* Storage Devices

Administrators can update, disable, enable, or troubleshoot hardware from this interface.

---

### Disk Management

Disk Management allows administrators to:

* Create partitions
* Extend volumes
* Shrink volumes
* Change drive letters
* Format storage devices

This section provided a better understanding of how Windows organizes storage resources.

---

### System Information

System Information provides detailed information about:

* Hardware Resources
* Components
* Software Environment

Examples include:

* Network adapters
* Installed services
* Running processes
* Environment variables
* Hardware details

This utility serves as a centralized source of system-related information.

---

### Resource Monitor

Resource Monitor provides real-time monitoring of:

* CPU
* Memory
* Disk
* Network

It helps identify:

* High resource consumption
* Network activity
* Memory usage patterns
* Disk read/write operations

---

### Command Prompt Utilities

Several useful commands were introduced:

| Command       | Purpose                      |
| ------------- | ---------------------------- |
| hostname      | Display computer name        |
| whoami        | Display current user         |
| ipconfig      | Display IP configuration     |
| ipconfig /all | Detailed network information |
| netstat       | Display network connections  |
| net help      | Display help information     |

These commands are frequently used by system administrators, SOC analysts, and cybersecurity professionals.

---

### Windows Registry

The Windows Registry is the central configuration database of Windows.

It stores information related to:

* User profiles
* Installed applications
* Hardware
* System settings
* Configuration data

Understanding the Registry helped me appreciate how much of Windows configuration is stored and managed behind the scenes.

## My Learning Experience

While completing this room, I initially assumed that most of these tools were only used by system administrators. However, as I progressed through the exercises, I started realizing how important they are for cybersecurity professionals as well.

One thing that stood out to me was Event Viewer. Before this room, I had seen Event Viewer mentioned in many walkthroughs and investigations but never understood its purpose. After exploring different log categories and event types, I could finally see why it is such an important tool during troubleshooting and incident investigations.

Another interesting discovery was Resource Monitor. I had previously used Task Manager to check system performance, but Resource Monitor provided much more detailed visibility into CPU, memory, disk, and network activity. It gave me a better understanding of what is happening behind the scenes on a Windows system.

The Command Prompt section was also valuable because it reinforced several commands that are commonly used in networking and cybersecurity environments. Seeing information from commands like `whoami`, `hostname`, `ipconfig`, and `netstat` helped connect theoretical networking concepts with practical Windows administration.

Overall, this room helped me move beyond simply using Windows as a daily operating system and start understanding how Windows works from an administrative and security perspective.
