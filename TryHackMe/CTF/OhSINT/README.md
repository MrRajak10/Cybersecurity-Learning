# OhSINT - TryHackMe (#001)

## Overview
OhSINT is a beginner-friendly OSINT "Open Source Intelligence" room that demonstrates how publicly available information can be collected, analyzed, and correlated to build a profile about an individual.
The room focuses on investigation and reconnaissance techniques using publicly available data sources.

## Skills Learned
* Open Source Intelligence (OSINT)
* Metadata Analysis
* Search Engine Reconnaissance
* Social Media Investigation
* GitHub Investigation
* Source Code Inspection
* Wi-Fi Reconnaissance
* Information Correlation

## Tools Used
* ExifTool
* Search Engines
* GitHub
* Wigle
* Browser Developer Tools

## Methodology
1. Analyzed image metadata.
2. Identified usernames and public profiles.
3. Investigated social media accounts.
4. Examined GitHub repositories.
5. Inspected website source code.
6. Correlated information from multiple sources.

## Key Takeaways
* Metadata can reveal valuable information.
* Public information can be combined to create a detailed profile.
* Multiple investigation paths can lead to the same result.
* OSINT is useful for both offensive and defensive cybersecurity.
* Small clues often lead to larger discoveries.

## Personal Reflection
This was my first CTF after completing the Pre-Security learning path.
Initially, I was unsure how to approach the room. Instead of searching for direct answers, I experimented with different investigation techniques, including reverse image searching and analyzing publicly available information.
Although I eventually watched a walkthrough, the experience helped me understand how an OSINT investigation is performed and how different pieces of information can be connected together.


The biggest lesson was learning the process of investigation rather than simply finding the answers.

## Conclusion

OhSINT provided a practical introduction to OSINT and demonstrated how publicly available information can reveal more than most people expect. The room strengthened my research and investigation mindset and provided a solid foundation for future OSINT challenges.
